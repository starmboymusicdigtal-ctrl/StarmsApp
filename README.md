# StarmsApp

Mobile-first PWA prototype for StarmsApp.

## Included in this first package
- Chats UI
- 20-hour Status UI
- Followers UI
- Voice/video call screens
- Creator profile using the supplied image
- Separate Creator Dashboard demo
- Global maintenance/feature controls demo
- PWA manifest + service worker

## Important
This first package is the front-end foundation. Data currently uses local browser storage so it can be previewed immediately.

Phase 2 connects Supabase so accounts, realtime chats, statuses, reports, followers, creator controls and server-side changes work across all users.

Private chats should only be accessible to conversation participants. Moderation should use user reports rather than secret reading of private chats.
